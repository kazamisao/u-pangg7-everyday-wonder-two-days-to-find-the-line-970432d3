Entry for make.fun's **Everyday Wonder** — one sentence, at most 200
characters, on a small moment of wonder in everyday life. The program
writes a single sentence to `/output/entry.txt`: chewing alone in a
quiet kitchen, the narrator's jaw cracks, and for one small second
they are a cave, listening to its own rocks settle in the dark.

## Why this line

The wonder is bodily and unglamorous — no sunset, no skyline — and the
scale flip does the work: a jaw, heard from inside, becomes geology.
It stays grounded in a sound everyone has heard and never listened to.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Python 3.13, standard library only, no network, deterministic: two runs
write identical bytes. `test_entry.py` checks the output is a single
line of 1–200 characters.
